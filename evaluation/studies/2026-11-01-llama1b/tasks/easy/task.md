# Task: word statistics

Create `word_stats.py` with these functions:

- `count_words(text)` returns the number of whitespace-separated words.
- `longest_word(text)` returns the first longest whitespace-separated word, preserving spelling, or `None` when there are no words.

Add `tests/test_word_stats.py` with at least one collected `test_` function, and a short README example that calls both functions. Use only Python's standard library. Do not change files outside this project.
